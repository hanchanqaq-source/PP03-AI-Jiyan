# PP03 V0.2-W1 行业穿透识别与分层展示设计

## 目标与边界

本设计只修正持仓分析页的行业识别与展示，继续停留在 V0.2-W1。保留 schema v3、`amount_pnl` / `shares_cost`、正式净值、历史净值、盘中估算、公开持仓、缓存与失败降级能力。不修改市场资讯、行业研究、投研首页、一级导航、路由或其他 Work。

行业事实不得来自基金名称或股票名称推断。基金名称只用于基金身份搜索。行业比例只使用带来源和日期的公开分类数据；缺失时显示未知或待穿透，不补造比例。

## 已确认根因

`017811 东方人工智能主题混合C` 的最新公开前十大持仓覆盖基金净值 83.47%。现有服务把盘中行情和股票行业合并为同一个 `stock_snapshot` 能力：东方财富批量证券接口返回 502 后，服务转用腾讯行情；腾讯能返回价格和涨跌，但没有行业字段。随后 `_industry_exposure` 在股票行业识别率为零时整段采用基金官方行业配置，并把宽泛的“制造业”通过 `_broad_industry` 映射为“其他”，形成“其他 86.67%、科技 8.05%、未知 5.28%”。

巨潮资讯公开的上市公司行业归属可以为同一批重仓股返回申万多级分类。对 `017811` 的实际验证结果为：

| 层级 | 穿透结果 |
|---|---|
| 一级行业 | 电子 74.78%、机械设备 8.69% |
| 二级行业 | 半导体 74.78%、通用设备 8.69% |
| 细分行业 | 半导体设备 67.74%、仪器仪表 8.69%、数字芯片设计 7.04% |
| 已识别公开持仓 | 83.47% |
| 官方未披露股票资产 | 11.25% |
| 非股票资产 | 5.28% |

上述穿透结果只覆盖公开前十大持仓，不把未披露部分归一化到 100%。

## 数据获取架构

### 解耦行情与行业分类

新增独立能力 `stock_industry_classification`，不再要求行情 Provider 同时提供行业：

- `stock_snapshot`：继续负责价格、涨跌和盘中估算；腾讯行情仍可作为有效备用源。
- `stock_industry_classification`：只负责股票多级行业事实和分类来源。
- `industry_allocation`：继续保存基金官方行业配置，但不再伪装成重仓股穿透结果。

行业分类 Provider 使用巨潮资讯上市公司行业归属接口，按前十大股票代码查询并缓存 24 小时。每只股票在可用记录中按以下标准优先级选择最新分类：

1. 申银万国行业分类标准 `008003`；
2. 申银万国旧标准 `008018`；
3. 巨潮行业分类标准 `008002`；
4. 中证现行或旧标准 `008014` / `008019`；
5. 证监会或上市公司协会分类 `008021` / `008001`。

返回的每只股票记录至少包含：

- `stock_code`、`stock_name`
- `primary_industry`、`secondary_industry`
- `detail_industry`、`fine_industry`
- `classification_standard`、`classification_code`
- `classification_changed_at`
- `source_name`、`source_reference`

Provider 可并发执行 HTTP 请求，但分类令牌生成必须在主调用线程完成，避免底层 JavaScript 运行时并发初始化。单只失败不得阻塞其他股票；失败代码进入未知构成明细。

### 缓存与降级

- 缓存键按排序后的股票代码集合生成，TTL 为 24 小时。
- 最新请求失败时，可使用明确标记的未过期缓存；过期缓存按既有 `stale` 规则显示。
- 巨潮分类部分成功时，按成功股票计算穿透比例，失败股票进入“未知”。
- 巨潮分类全部失败时，重仓股穿透模块显示不可用；官方行业配置仍独立展示，不混入穿透比例。
- 官方行业配置中的宽泛类别原样保留。`制造业` 显示为 `制造业（待穿透）`，比例、截止日期和来源均不改变。

## 行业计算合同

### 单基金行业暴露

`FundIndustryExposure` 在保留旧字段兼容的同时新增以下结构：

```text
official_allocation:
  exposure[]: name, display_name, weight_pct, requires_lookthrough
  stock_exposure_pct, as_of_date, source_name, source_reference

lookthrough:
  primary[]: name, weight_pct
  secondary[]: name, weight_pct
  detail[]: name, weight_pct
  identified_coverage_pct
  other_pct
  unknown_pct
  undisclosed_stock_pct
  non_stock_pct
  disclosure_date
  source_name, source_reference, classification_standard

industry_chain_tags[]:
  id, name, weight_pct, evidence_level, source_name

other_constituents[] / unknown_constituents[]:
  stock_code, stock_name, weight_pct, reason
```

一级、二级和细分比例均直接累加公开持仓在基金净值中的原始占比，不重新归一化。已识别覆盖率等于成功分类的公开持仓权重。未披露股票资产和非股票资产保持独立字段。

“其他”与“未知”的定义固定为：

- 其他：已经获得有效行业记录，但在当前所选层级缺少可展示名称（例如只有细分类而没有一级分类）；必须保留原始分类和对应持仓，不能改称未知。
- 未知：公开持仓缺少分类、分类请求失败、或股票资产未披露；必须说明具体代码或“未披露股票资产”。

### 产业链与主题标签

标签只能由股票行业分类文字产生，不读取基金名称。规则对一级、二级、细分行业字段进行匹配，例如：

- 半导体设备 → `半导体设备`、`半导体`
- 数字芯片设计 / 集成电路设计 → `芯片设计`、`半导体`
- 软件开发 / IT 服务 → `软件`
- 消费电子 → `消费电子`
- 机器人 / 自动化设备 → `机器人`

标签权重为命中该标签的公开持仓原始权重之和。若公开分类事实不能支持“人工智能”，即使基金名称含“人工智能”也不显示该标签。

### 组合行业集中度

组合只使用各基金的 `lookthrough` 结果，按当前参考市值权重聚合一级、二级和细分行业。官方行业配置不参与组合穿透比例。

- 一只基金：标题为“该基金行业暴露”。
- 两只及以上基金：标题为“组合行业集中度”。
- 组合已识别覆盖率、其他比例和未知比例均按基金参考市值加权。
- 组合产业链标签按基金参考市值和基金内标签权重聚合。

## 前端展示设计

### 高密度持仓行

基金名称和代码下增加一行最多四个“系统识别行业 / 产业链”紧凑标签。优先顺序为高权重产业链、二级行业、一级行业；相同名称去重。没有可靠分类时显示一个弱化标签“行业待识别”，不使用基金名称补标签。行高只做必要增加，仍保证桌面一屏显示多只基金。

### 行业暴露模块

行业模块分为三块，不能共用一个比例图：

1. **重仓股穿透后的行业暴露**：默认展示一级行业条形图，并提供一级 / 二级 / 细分切换；显示已识别覆盖率、未知比例、未披露股票资产、持仓披露日期、分类标准、来源和计算依据。
2. **官方行业配置**：逐条显示官方原始类别、原始比例、截止日期和来源；宽泛类别增加“待穿透”后缀。
3. **产业链 / 主题标签**：显示来自股票分类的标签及估算权重，明确“基金名称未参与行业事实判断”。

当公开前十大持仓覆盖率低于 50% 时，在穿透图上方显示：

> 行业暴露仅基于公开持仓估算，未披露部分未归一化。

为避免对较高覆盖率造成过度承诺，只要仍有未披露股票资产，计算依据区域也持续显示“未披露部分未归一化”。

“其他”和“未知”以可点击行展示；点击后在模块内展开构成明细，不打开新的全局弹窗。未知明细可以包含具体股票以及“未披露股票资产”汇总项。

### 基金详情抽屉

详情抽屉复用相同的三块数据，但展示完整来源、截止日期和所有构成明细。原有公开持仓、数据质量和缓存标记保留。`data_quality` 新增行业分类来源状态，不删除 `industry_allocation` 状态。

## 错误与真实性规则

- 不得把官方配置、重仓股穿透和产业链标签合并为一个比例。
- 不得把“制造业”等宽泛官方类别静默映射为“其他”。
- 不得从基金名称或股票名称生成行业事实。
- 不得把未知、未披露股票资产和非股票资产归一化到已识别行业。
- 数据来源失败时显示 `暂无可靠数据`、缓存或过期状态，不使用静态演示值。
- 同一股票存在多个分类标准时只使用已声明优先级中的最高优先级最新记录，并展示标准名称。

## 测试与验收

后端测试覆盖：

1. 行情缺少行业字段时仍调用独立行业分类能力；
2. 多分类标准选择申万现行标准；
3. 部分股票分类失败时保留已识别比例和未知构成；
4. “制造业”在官方配置中显示“制造业（待穿透）”，不进入穿透“其他”；
5. 一级、二级、细分和标签比例不归一化；
6. 组合按参考市值聚合穿透结果；
7. 一只基金和多基金标题条件的数据合同；
8. 缓存、过期与全部失败降级。

前端测试覆盖：

1. 高密度持仓行显示最多四个系统行业 / 产业链标签；
2. 单基金标题为“该基金行业暴露”，多基金标题为“组合行业集中度”；
3. 官方配置、穿透暴露和产业链标签分区显示；
4. 一级 / 二级 / 细分切换；
5. 其他与未知展开构成；
6. 低覆盖率和未归一化提示；
7. 来源、日期、覆盖率和分类标准可见。
