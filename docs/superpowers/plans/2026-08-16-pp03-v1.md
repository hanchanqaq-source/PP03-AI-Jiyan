# PP03 基金投研首版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Vibe-Research 上增量交付可本地运行的 PP03 四页基金投研样板，完成共享标签闭环、连续行业报告、标签资讯过滤和本地基金持仓。

**Architecture:** 前端以 `features/tags`、`features/news`、`features/industry` 和 `features/fund-portfolio` 形成独立边界，复用现有 API 客户端与视觉体系。页面偏好使用安全 `localStorage`，基金持仓使用新建的用户目录 JSON 和独立 FastAPI 路由；股票持仓、资讯抓取、行情与 AI 模块保持原样。

**Tech Stack:** React 19、TypeScript 5.7、Vite 6、Tailwind CSS 3、ECharts 6、FastAPI、Pydantic、pytest、Vitest、Testing Library。

## Global Constraints

- 基于 Vibe-Research 现有架构增量开发，不进行无关大规模重构，不删除现有功能。
- 所有用户数据默认保存在本地。
- AI 只总结和解释已提供数据，不能生成行情、净值、持仓、资金或行业指标。
- 真实数据必须显示来源与更新时间；缺失数据显示“暂无可靠数据”。
- 示例内容必须显示“示例数据”或“开发占位数据”。
- 四个主页面是投研首页、市场资讯、行业研究、持仓分析；原有页面保留。
- 首批完整报告模板是半导体、存储、机器人，其他标签显示“该行业报告模板正在完善”。
- Windows 桌面浏览器按 1366 至 1920 像素设计，标签溢出横向滚动，行业报告连续阅读。
- 不实现交易、券商连接、公开部署、多人账户、移动 App、自动更新、复杂量化预测或唯一基金推荐。
