# PP03 V0.2-W1 Portfolio Data Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 04 持仓分析升级为真实基金识别、官方净值、公开持仓、行业暴露、用户盈亏和组合重复度的本地闭环。

**Architecture:** FastAPI 新增独立 `fund_data` 适配层，统一 Provider、缓存、元数据与计算；本地持仓只保存用户真值并迁移 V0.1。React 只消费聚合 API，以表格、右侧详情抽屉、SVG 净值图和证据状态展示部分成功结果。

**Tech Stack:** Python 3.10+、FastAPI、Pydantic、requests、AKShare、pandas、pytest、React 19、TypeScript 5.7、Vite 6、Tailwind CSS 3、Vitest、Testing Library。

## Global Constraints

- 唯一规格源是用户提供的 V0.2-W1 计划书。
- 只修改 04 持仓分析及数据模型复用所必需的接口；不重做另外三个主页面。
- 分支固定为 `codex/pp03-v0.2-w1-portfolio`，不得改 `main`、合并 V0.1 或 force push。
- 不伪造金融数字；真实、披露、估算、用户输入、缓存、过期和失败必须区分。
- 用户文件、备份、缓存、`.env`、Token 和 API Key 不进 Git。
- 旧成本语义不确定时要求用户确认，不自动猜测。
- 不新增一级导航；基金详情保留在持仓分析内部。
- 不输出买卖建议、基金推荐、收益预测或自动交易操作。
