# PP03 V0.2-W2 Closeout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish V0.2-W2 by preserving the completed query-scope repair, adding bounded Chinese translation, inspectable source failures, and safe cache lifecycle management, then prove the result in the browser and push only the W2 branch.

**Architecture:** The backend remains the authority for query snapshots, translation caching, source diagnostics, and deletion eligibility. The frontend sends the existing local AI configuration only for the current visible English events, merges translations only into the matching query/snapshot, and renders diagnostics/cache controls without deriving new evidence. Cache cleanup scans only explicitly owned roots and never deletes user truth, valid or pinned entries, tracked evidence, source code, or lock files.

**Tech Stack:** Python 3.12, FastAPI, Pydantic, pytest, React 19, TypeScript, Vitest, Testing Library, Tailwind CSS, Vite, existing OpenAI-compatible/CLI model adapters, existing in-app browser control runtime.

## Global Constraints

- Do not migrate `D:\AI_Workspace` or change project roots.
- Preserve the current uncommitted query-scope implementation and do not repeat its already-passed focused development tests.

- Do not add a third-party translation service or persist AI credentials server-side.
