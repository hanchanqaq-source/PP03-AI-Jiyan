# PP03 V0.2-W2 Query Scope Consistency Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every W2 mode, event list, sidebar statistic, failure fallback, and detail snapshot use exactly the current query scope.

**Architecture:** The backend owns the canonical five-stage filter and derives all response sections from one filtered list. The frontend stores complete successful responses in a map keyed by the canonical query and rejects stale or mismatched responses before rendering.

**Tech Stack:** Python 3.12, FastAPI, pytest, React 19, TypeScript, Vitest, Testing Library, Codex Computer Use `@oai/sky`.
