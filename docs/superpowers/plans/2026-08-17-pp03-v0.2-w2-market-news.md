> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade `02 市场资讯` from an RSS list into a deterministic event radar and public-holdings impact board.

**Architecture:** Keep `newsradar` as the raw RSS/cache boundary and add a focused `backend/news_intelligence` package for normalization, conservative clustering, W1 evidence-based relationships, ranking, filtering, and API composition. The React page consumes the backend event contract, reuses the shared page-tag system, and renders a dense 70/30 event workspace with accessible dialogs/drawers and honest failure states.

**Tech Stack:** Python 3.11, FastAPI, pytest, React 19, TypeScript 5.7, Vitest, Testing Library, Tailwind CSS, existing browser-control runtime.
