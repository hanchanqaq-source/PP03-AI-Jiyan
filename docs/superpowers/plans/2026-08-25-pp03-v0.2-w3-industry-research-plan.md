# PP03 V0.2-W3 行业研究工作台实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不降低 A2-W1 可信准入标准的前提下，把行业研究页实现为真实数据优先、缺失即空、可追溯且按行业隔离的连续研究报告；存储是首个完整布局样板，半导体与机器人使用差异化模板。

**Architecture:** 后端先把来源观察、证据核验、规则结论和原子可信快照分层，再通过单一只读报告 API 交付八段报告；前端一次读取一个 `industry_id` 的整份快照，显示四轴状态和证据，不在浏览器拼接可信结论。刷新期间保留上一可信快照，所有真实来源验证与日常离线测试分开。

**Tech Stack:** Python 3.12、FastAPI、dataclasses/JSON 原子存储、pytest、React 19、TypeScript 5.7、Zustand、Tailwind CSS、Vitest、Testing Library、Vite、隔离 Playwright 1.62.1 + Chromium。

**Spec:** `docs/superpowers/specs/2026-08-25-pp03-v0.2-w3-industry-research-design.md`

## 现状审计与数据裁决

### 当前真实实现

- `frontend/src/pages/IndustryResearch.tsx` 是标签壳加静态八段模板，并通过旧 Radar 旁路取最多 8 条事件；没有行业报告 API。
- `frontend/src/features/industry/templates.ts` 的指标主要为空或开发占位；`TruthStatus` 只有三态。
- `/api/industry` 是行业异动排名，不是报告合同，不能直接当行业周期、资金或估值。
- 标签有多选、激活、删除和排序，但没有真正创建自定义标签，也没有键盘排序。
- A2-W1 的新闻/证据流水线和基金披露穿透可复用；现有行业页没有消费它们的可信快照。

### 可直接复用

- `backend/data_sources/` 的 provider catalog、`ProviderValue`、路由和健康状态；
- `backend/news_pipeline/` 的可信发布、历史窗口、冲突和旧快照；
- `backend/evidence_verification/` 的来源身份、独立性、支持/反驳和冲突优先；
- `backend/fund_data/` 的官方配置、披露持仓、证券代码穿透和证据等级；
- `frontend/src/features/tags/`、既有八段锚点、Layout/PageHeader 和市场资讯状态语言。

### 当前只能为空

- DRAM/NAND 价格、HBM 需求、行业库存、产能利用率、行业资本开支、服务器需求、消费电子需求；
- 板块资金、ETF 份额、行业估值和历史分位；
- 未经官方披露/代码关系确认的公司关系、基金行业暴露；
- 基金排行榜、买入建议、公司订单推断和自由生成的周期结论。

以上字段只有在本计划的来源资格任务通过后才可由空态升级。公开网页可访问不等于已获准自动采集；历史/下载会员数据不作为免费实现前提。
