## Provider 顺序

1. `eastmoney-direct`：搜索、正式净值序列、股票快照。
2. `tencent-quote`：股票行情备用源。
3. `akshare-eastmoney`：基金目录、资料、正式净值备用、持仓和行业配置。
4. `akshare-danjuan`：基金资料备用源。

每个能力返回统一元数据：`source_name`、`source_reference`、`data_type`、`as_of_date`、`fetched_at`、`status`、`is_cached`、`is_stale`、`provider`、`fallback_used` 和 `message`。单项失败不会把聚合接口整体变成伪造成功；没有可靠数据时返回 `unavailable` 或 `error`。

## 有限实源验收

- `000001` 华夏成长混合：代码/名称搜索、基本资料、正式净值、历史净值、2026-Q2 前十大持仓、行业配置和数据质量元数据。
- `000021` 华夏优势增长混合：用于验证多基金重复持仓；与 `000001` 识别到 7 只重复证券。
- `519029` 华夏稳增混合：用于验证不同持仓结构、组合计算和公开披露。
- 组合验收结果：总成本 1,620.00 元，正式净值对应市值 2,036.10 元，累计盈亏 416.10 元；行业已识别覆盖 88.15%，未知部分 11.85%。这些数值仅对应隔离验收目录与当次公开数据快照。

## 缓存与降级实测

验收时将 `000001` 正式净值缓存标记为过期，并临时阻断测试进程的上游访问。接口返回 `status=stale`、`is_cached=true`、`is_stale=true`、`original_status=official`，页面显示“过期缓存 · 已过期”和上次成功时间。测试后已恢复原缓存有效期和正常联网进程。
