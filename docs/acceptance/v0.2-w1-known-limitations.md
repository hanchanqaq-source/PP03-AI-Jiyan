# PP03 V0.2-W1 已知限制

核验日期：2026-08-16（Asia/Shanghai）

1. 公开数据源没有可用性 SLA。东方财富、腾讯或其页面结构变化时，对应模块会显示失败、备用源或过期缓存；不会用 AI 或静态演示值补齐金融数字。
2. 基金持仓来源能提供报告期和期末日期，但当前适配器未取得独立的实际公开日期。因此 `public_date` 保持为空，并明确提示“公开日期字段暂缺”。
3. 行业事实优先来自最新公开前十大持仓对应的巨潮资讯股票行业分类；官方行业配置只作为独立补充证据。`制造业` 等宽泛分类显示为“待穿透”，不再静默落入“其他”，也不再替代穿透比例。
4. 腾讯行情备用源不提供行业字段，但行情与行业事实已拆为两个独立能力：行情源切换不会用股票名或基金名补造行业；巨潮行业分类不可用时，穿透层显式降级，官方配置仍独立保留。
5. 盘中估算只在基金类型、持仓披露新鲜度、持仓覆盖率和行情覆盖率同时达标时显示。不同公开测试基金可能分别显示估算值或“暂无可靠数据”，不会把前十大股票涨跌简单称为实时净值。
6. 不同基金的数据能力可能不同。货币基金、FOF、QDII 或无可靠股票披露的基金会保留正式净值能力，但持仓穿透、A 股行业和盘中估算可以为空。
7. 历史净值曲线只连接相邻间隔不超过 7 天的数据点，避免把长缺口伪装成连续行情；它不补造缺失交易日数据。
8. 生产构建通过，但 Vite 报告主入口压缩前 654.12 kB（gzip 190.43 kB），超过默认 500 kB 提示线；同时存在一个 0 kB 的 `vendor-charts` 分块。该体积告警不阻塞本 Work，后续若优化必须另行授权，不能擅自进入 V0.2-W2。
9. 后续 V0.2-W1 验收临时数据统一使用 `D:\AI_Workspace\04-Projects\PP03-AI-Jiyan\.tmp\acceptance\v0.2-w1`，通过 `VR_DATA_DIR` 与用户默认持仓隔离。仓库忽略 `.tmp/`，执行方必须在验收收口的 `finally`/等价步骤中自动删除该目录；本次验收临时数据已清理，不作为长期限制或证据保留。
10. 依赖测试存在一条 Starlette/httpx 弃用告警；当前受限目录下 Pytest 还会报告无法写入 `.pytest_cache` 的非阻塞告警。153 项离线测试全部通过。
11. 本轮包含 live 标记的完整后端测试为 170 passed、1 failed；失败项是非持仓模块访问 `reportapi.eastmoney.com` 的研报接口连接超时。最终确定性后端套件 159 项全部通过，017811 巨潮行业分类真实调用和页面穿透验收成功。联网测试仍受公开数据源可用性影响，不能等同于本地回归结果。
12. 股票行业分类的“数据截至”是上市公司行业归属记录的最近变更日期，不等同于基金持仓披露日期；页面分别显示分类标准/来源和基金持仓披露日期，避免把两类日期混为一谈。
13. Windows Computer Use 在本轮连接 Chrome 时因无法高置信确认窗口 URL 而按安全策略停止；最终浏览器验收和三张截图由 Codex 内置浏览器完成。该限制只影响本轮 Windows 屏幕控制路径，不影响页面、API 或截图证据。
