# PP03 V0.2-W1 已知限制

核验日期：2026-08-16（Asia/Shanghai）

1. 公开数据源没有可用性 SLA。东方财富、腾讯或其页面结构变化时，对应模块会显示失败、备用源或过期缓存；不会用 AI 或静态演示值补齐金融数字。
2. 基金持仓来源能提供报告期和期末日期，但当前适配器未取得独立的实际公开日期。因此 `public_date` 保持为空，并明确提示“公开日期字段暂缺”。
3. 自动行业暴露优先使用股票快照行业；当该字段缺失时使用基金公开行业配置。公开行业大类到产品七大方向的映射仍较粗，例如“制造业”会落入“其他”，页面同时保留原始一级/二级行业和计算依据。
4. 腾讯行情备用源不提供行业字段。切换到该源时，行情可能可用而行业识别覆盖下降，两者不会混为同一覆盖率。
5. 盘中估算只在基金类型、持仓披露新鲜度、持仓覆盖率和行情覆盖率同时达标时显示。当前三只公开测试基金的组合概览按规则显示“盘中估算暂不可用”，不会把前十大股票涨跌简单称为实时净值。
6. 不同基金的数据能力可能不同。货币基金、FOF、QDII 或无可靠股票披露的基金会保留正式净值能力，但持仓穿透、A 股行业和盘中估算可以为空。
7. 历史净值曲线只连接相邻间隔不超过 7 天的数据点，避免把长缺口伪装成连续行情；它不补造缺失交易日数据。
8. 生产构建通过，但 Vite 报告主入口压缩前约 636.92 kB，超过默认 500 kB 提示线。该体积告警不阻塞本 Work，后续若优化必须另行授权，不能擅自进入 V0.2-W2。
